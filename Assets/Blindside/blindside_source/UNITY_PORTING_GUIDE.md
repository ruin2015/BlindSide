# BLINDSIDE — 유니티 이전 가이드

이 문서는 현재 웹 버전(HTML + JavaScript + three.js)을 유니티(C#)로 옮길 때 참고할 설계 요약입니다. ChatGPT에 코드를 넘길 때 이 문서를 먼저 붙여 넣으면, 각 파일이 무슨 역할인지와 게임 규칙의 수치를 정확히 전달할 수 있습니다.

## 2. 좌표계

- 맵은 가로 26 × 세로 20 격자이고, 한 칸 = 1 유닛입니다.
- 칸의 중심이 정수 좌표입니다. 칸 (x, y)는 x−0.5 ~ x+0.5 범위를 차지합니다.
- 3D에서는 격자 x → 월드 X, 격자 y → 월드 Z입니다. 유니티도 같은 방식이면 편합니다(`new Vector3(x, 0, y)`).
- 바라보는 방향(facing)은 격자 기준 라디안 각도입니다(0 = +x, π/2 = +y). 유니티 회전으로는 `Quaternion.Euler(0, -facing * Mathf.Rad2Deg, 0)`이 대응합니다(모델이 +X를 바라보도록 만든 경우).
- 유닛 위치는 연속 좌표(float)이고, 반지름은 0.28입니다.

## 3. 맵 문자 정의

| 문자 | 의미 |
|---|---|
| `.` | 외부 바닥 |
| `,` | 내부 바닥 |
| `W` | 파괴 가능한 벽(나무벽) |
| `H` | 파괴 불가 기둥 |
| `o` | 상자(통과 불가, 시야 통과) |
| `E` | 구출 지점 |
| `c` | 고정 감시카메라 |
| `h` | 인질 시작 위치 |

- 벽은 가로·세로로 이어진 줄(run)을 2칸씩 잘라 **패널** 단위로 관리합니다.
- 강화, 파괴, 전류, 거울은 모두 패널 단위로 적용됩니다.
- 긴 벽은 패널이 여러 개라서 강화를 여러 번 해야 전부 강화됩니다.
- 건물 범위는 x 3~22, y 5~17입니다. 공격팀 배치는 이 범위 밖에서만 가능합니다.

## 5. 핵심 규칙과 수식

### 시야
- **범위:** 몸 주변 반경 2.3의 원형 시야와, 바라보는 방향 ±0.68rad(약 39°)·사거리 10의 부채꼴 시야를 합친 영역입니다.
- **사선(LOS):** 두 점 사이를 0.1 간격으로 샘플링해서, 지나는 칸 중 불투명한 칸이 있으면 막힌 것으로 봅니다.
- **불투명한 칸:** 벽, 기둥, 가스 칸이 해당합니다. 거울 패널은 방어팀에게만 투명합니다.
- **보조 시야:** 드론(공격팀, 반경 2.5)과 카메라(방어팀, 반경 3.2)는 원형 시야만 가집니다. 교란 중인 레이스는 이 둘에 잡히지 않습니다.
- **시야 폴리곤:** 광선을 여러 방향으로 쏴서 만듭니다(원형 구간 5° 간격, 부채꼴 구간 0.9° 간격, 0.05 단위로 진행).

### 명중률 (`hitChance`)
```
c = 무기 명중
if 산탄총 && 거리 ≤ 2.5: c += 15
if 거리 > 사거리: c -= (거리 - 사거리) × 12
c -= 관통한 벽 수 × 22
if 선제공격: c += 15
clamp(c, 5, 95)
```

### 헤드샷 (`headshotChance`, 명중한 탄마다 판정)
```
c = 무기 기본 헤드샷
if 선제공격: c += 18
if 거리 > 사거리: c -= 5
if 거리 ≤ 2.5: c += 4
c -= 관통 벽 수 × 4
clamp(c, 2, 60)   // 인질은 0
```
- 헤드샷 피해는 2배입니다.
- 헤드샷이 나면 다음 연출이 순서대로 나옵니다: HEADSHOT! 배지, 화면 플래시와 집중선, 150ms 히트스톱(트윈과 이펙트 정지), 카메라 줌 펀치, 화면 흔들림.

### 피해와 사격
- 선제공격이면 발당 피해에 ×1.4를 곱합니다.
- 사격할 수 있는 최대 거리는 사거리 + 4입니다.
- 강화벽, 거울, 기둥은 탄이 뚫지 못합니다. 일반 벽은 관통합니다.
- 대상이 방패를 전개한 상태에서 정면에서 쏘면 피해가 0입니다.

### 조우 (이동 중 0.2m마다 판정)
1. **나만 적을 봄:** 사람이 조작 중이면 공격할지 무시할지 선택합니다. 공격하면 선제공격 후 이동을 멈춥니다.
2. **서로 봄:** 속도(mv, 자극제 +1)가 높은 쪽이 먼저 쏘고, 둘 다 멈춥니다.
3. **적만 나를 봄:** 적이 선제공격합니다.
- 선제공격으로 상대가 쓰러지면 반격은 없습니다.
- 서로 탄이 통하지 않는 상황(예: 거울 너머)이면 위치 표시만 남깁니다.

### 턴 흐름
- **공격팀으로 시작:** 인트로 → 배치 단계(건물 외부에 로프 강하) → 1라운드
- **방어팀으로 시작:** 준비 단계(인질 방에서 시작, 강화 최대 10회, 능력 설치) → 1라운드
- 한 라운드는 공격팀 페이즈 → 방어팀 페이즈 순서이고, 15라운드를 넘기면 방어팀이 승리합니다.
- **승리 조건 (둘 중 하나):**
  - 공격팀: 인질 호송(호송 대원이 구출 지점에 도착) 또는 방어팀 전원 제압
  - 방어팀: 제한 시간까지 버티기 또는 공격팀 전원 제압
- 인질을 사살한 팀은 패배합니다.

### AI 요약
- **방어팀:** 보이는 적이 있으면 사격합니다. 알려진 적(보이거나 표시된 적)이 사거리 안에 들어오는 위치가 있으면 이동해서 조준합니다. 인질에서 9m 이상 벗어나지 않습니다(레이스는 예외). 미아즈마는 알려진 적에게 가스를 던집니다.
- **공격팀:** 목표(인질, 호송 중이면 구출 지점, 인질이 없으면 가장 가까운 적)까지의 거리장을 만들고 이동 가능 범위에서 최선의 칸으로 이동합니다. 브리처는 벽을 뚫으면 목표까지 4칸 이상 단축될 때 벽을 뚫습니다. 1~2라운드에는 드론 정찰을 합니다.

## 6. 유니티 구조 제안

- **데이터:** `OperatorData`, `WeaponData`를 ScriptableObject로 만들고, 위 표 수치를 그대로 옮깁니다.
- **맵:** `MapGrid` 클래스가 맵 문자열을 파싱해서 `TileType[,]`과 `Panel` 목록을 만들고, 벽 프리팹(나무/강철 셔터/거울/구멍)을 배치합니다.
- **시야:** 판정은 JS 로직을 그대로 C#으로 옮기는 게 가장 정확합니다(Physics 레이캐스트보다 격자 샘플링이 결과가 같습니다). 표현은 시야 폴리곤을 동적 `Mesh`로 만들고, 안개는 26×20 `Texture2D`(Bilinear 필터)를 바닥 위 쿼드에 입히면 됩니다.
- **경로:** 현재의 8방향 다익스트라 + 경로 다듬기를 그대로 옮기는 것을 권장합니다. NavMesh를 쓰면 벽이 부서질 때마다 다시 구워야 해서 번거롭습니다.
- **비동기 흐름:** JS의 `async/await`는 코루틴(`IEnumerator` + `yield return`)이나 UniTask로 옮기면 구조를 거의 그대로 유지할 수 있습니다. `sleep(ms)`는 `WaitForSeconds`, `tween`은 DOTween에 대응합니다.
- **히트스톱:** 헤드샷 순간 `Time.timeScale = 0`으로 두고 `WaitForSecondsRealtime(0.15f)` 뒤에 복구하면 됩니다.
- **카메라:** 톱뷰는 높이 h, 뒤로 h·tan(0.32) 떨어진 위치에서 대상을 바라봅니다. 인트로는 Cinemachine + Timeline으로 궤도 샷과 헬기 비행 경로(4개 지점)를 옮기면 됩니다.
- **UI:** 명령 메뉴, 대원 목록, 상세 패널, 확인 창, 교전 컷인, 배너를 각각 프리팹으로 만듭니다. CSS의 색상 토큰은 `--paper #eceef0`, `--ink #14161a`, `--blu #1f96e8`, `--foe #e5364d`, `--acc #ffc81e`입니다.
- **일러스트:** SVG 생성기를 C#으로 옮기기보다, 브라우저에서 이미지로 저장하거나 새로 그린 PNG를 스프라이트로 쓰는 편이 효율적입니다.

## 7. ChatGPT로 이전할 때 권장 순서

1. 이 문서와 `01_core_data_map_vision.js`를 주고, `GameData`·`MapGrid`·`VisionSystem`·`PathPlanner` C# 클래스를 만들게 합니다. 이 단계는 유니티 에디터 없이 단위 테스트로 검증할 수 있습니다.
2. `04_gameplay_combat_ai.js`를 주고, 코루틴 기반의 `CombatSystem`·`MovementSystem`·`AbilitySystem`·`TurnManager`·`EnemyAI`를 만들게 합니다.
3. `03_renderer_threejs.js`를 참고 자료로 주고, 벽·유닛 프리팹 생성, 시야 메시, 안개 텍스처를 만들게 합니다.
4. `05_ui_input_intro.js`와 `00_markup_and_styles.html`을 주고, 입력(경로 드래그), HUD, 인트로 연출을 만들게 합니다.

한 번에 전부 붙여 넣으면 답변이 잘리거나 내용이 섞이기 쉬우니, 위 순서대로 파일 하나씩 요청하는 것을 권장합니다.
